# Configurable v0.1 beta implementation plan

Spec: ../design.md. User approved implementation of a configurable GitHub beta. Scope is source preparation; publication and a new live helper installation are separate actions.

## Global constraints

Do not modify the working personal installation. No UI input during automated tests. No private paths, IPs, serials, scans, certificates or session history in source. No network runtime. Keep changes in this new repository; synced project sources are read-only. Tests precede implementation. App permissions belong to the app, never Codex. Compile and sign without launching it.

### Task 1: State engine and local runtime

Own src/core.js, src/runtime.js, tests/core.test.cjs, tests/runtime.test.py and fixtures if needed. Implement the exact API and snapshot contract in docs/design.md. Write failing tests first. Pure core must cover normal repeated cycles, startup arming, duplicate suppression, cancelled choice, background/dialog refusal, invalid/ambiguous metadata, wrong destination readback, collision, no Save retry, timeouts, dispatch failure, restart and stable JPEG verification. Runtime must cover atomic settings/state, permissions, destination validation, no symlink/nonregular outputs, errors, bounded sanitized logs and JSON values including unicode/quotes. Use Foundation JXA, no external runtime dependency or UI input. All state is external to the app. Read config on each request, persist action reservation before emitting it. Return visible errors rather than throwing uncontrolled exceptions. Write a test report; no commits while another agent may be committing shared files.

### Task 2: App integration

Own src/helper.applescript, src/native-click.js, tests/adapter_test.py. Implement safe snapshot gathering, two-snapshot action guards, single-field folder setting and readback, native click adapter, foreground/PID/window/sheet/target geometry checks. Support background read-only snapshots. JSON bridge uses Foundation serialization with no hand-built user-string quoting. Dock reopen opens settings menu and native folder picker; first run disabled; explicit enable arms at idle; status explains errors/recovery. Exceptions pause and report a sanitized code. Avoid persistent property changes inside the app bundle. Exercise bridge and fake UI decision handlers without sending real input. Compile/build tests are required. Never launch alongside live helper.

### Task 3: Distribution and instructions

Own scripts/build.sh, scripts/install.sh, scripts/test.sh, README.md, docs/README.de.md, LICENSE, CHANGELOG.md, SECURITY.md, .gitignore, .github/workflows/check.yml. Produce reproducible source build and explicit non-destructive install script. Compile stay-open AppleScript app, bundle core/runtime/native resources before ad-hoc signing. Set stable bundle ID, display name, version and permission usage description. Output in build/ (ignored). Optional signing identity may be passed explicitly. Never launch, install, modify macOS permissions or autostart during build. Install defaults ~/Applications and refuses existing target unless --replace; explain quit-first and new permission identity after rebuild. Public docs start with beta support boundary, build/use/recovery, configuration, own app permissions, no dual helpers, test vs hardware status, removal, troubleshooting and privacy. English README and German guide, MIT contributors license. No scans, internal paths or bundled Epson software. CI runs tests/build on macOS and core tests on Node. Tests need no actual GUI permission.

### Task 4: Review and release preparation

Run complete tests, build/signature verification, privacy/path and shell checks. Request independent whole-branch review of integration/safety/docs, fix demonstrated issues with regression coverage. Record actual validation and untested hardware status honestly. Create a source archive excluding generated/private files. Keep local git branch clean and deliver clickable source/build links. Ask for GitHub destination/publication only once package is concrete.
